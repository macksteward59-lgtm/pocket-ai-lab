CONFIGURATION

Model settings

Connect a local llama.cpp server. Cloud routing is intentionally not enabled until a secure server-side provider is configured.

Provider configuration

Chat and Agent Team both call the local llama.cpp InferenceProvider. Set LLAMACPP_BASE_URL (default http://127.0.0.1:8080) on the server. LLM_BASE_URL ending in /v1 selects the OpenAI-compatible API. No API key is stored in this browser or sent by the local adapter.

Local endpoint only

The browser talks only to this app server. "Local model ready" appears after a loopback health check succeeds. A remote URL is not described as private.

COLLABORATION

Agent team

The core roles perform independent analysis, cross-review, challenge, revision, verification, and synthesis. Connect a local llama-server to run real model calls. Agent output remains untrusted and cannot authorize actions.

Run a local agent team

Real model calls through Director, Reasoner, Researcher, Engineer, Critic, and Validator roles. Local llama.cpp inference only.
