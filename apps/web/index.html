CONFIGURATION

Model settings

Connect a local llama.cpp server. Cloud routing is intentionally not enabled until a secure server-side provider is configured.

Provider configuration

Set LLM_BASE_URL, LLM_MODEL, and optional LLM_API_KEY in the server environment. Credentials are never stored in this browser.

Local endpoint only

The browser connects to this instance's server. The server forwards requests to the endpoint configured in its environment. Do not enter secrets in this browser.
